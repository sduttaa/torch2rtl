# Window-aware actor selection

Measuring line-memory alternatives and using the proved window-refill bounds
improved the same four-bit-hidden-activation, INT8-weight graph's sampled RTL
throughput. The requested accuracy, fabric-only deployment and 30-FPS result
remain incomplete.

## Catalogue and selection

The parallel line layout was synthesized for **all 191 arithmetic configurations**
in the existing packed-layout catalogue. These are explicit experiment inputs,
not new compiler defaults or model-specific implementation rules. Some parallel
layouts use more BRAM; others have the same BRAM count and lower logic cost.
The solver can now trade these measured costs against their timing bounds.

The diagnostic selection problem keeps measured resources and the intrinsic
period lower bounds generated by the existing actor contracts, including the
new window-refill paths. It omits graph FIFO occupancy and inter-actor timing
coupling. It is a **necessary-condition relaxation**, not a complete schedule.
The production `schedule-network` path still places scheduling and FIFO
occupancy directly in CP-SAT.

| Selected graph | Necessary period bound | LUT equivalents | FFs | BRAM | DSP byte slots |
| --- | ---: | ---: | ---: | ---: | ---: |
| Separate convolution and pool | 3,875,676 | 20,700 | 8,108 | 46 | 96 |
| Optional proved convolution/pool fusion | 3,807,732 | 20,657 | 7,633 | 46 | 96 |

Resource costs include the depth-one FIFOs selected by this relaxation. They
leave essentially no resource reserve, and depth-one choices do not establish
correct FIFO occupancy. Whole-design synthesis, a feasible FIFO allocation and
place-and-route remain required. These are optima only within this measured
finite catalogue and relaxation.

## Numerical RTL verification

Both selections match **96,768 output pixels** from the same three reference
images under random source and sink stalls. Numerical verification uses one
frame of FIFO capacity per edge, which exceeds fabric memory.

| Configuration | Frame completion cycles | Observed inter-frame cycles |
| --- | --- | --- |
| Previous packed-layout selection | 5,057,795; 9,040,482; 13,023,168 | 3,982,687; 3,982,686 |
| New separate-actor selection | 4,913,764; 8,789,442; 12,665,114 | 3,875,678; 3,875,672 |
| New fused selection | 4,791,917; 8,599,649; 12,407,380 | 3,807,732; 3,807,731 |

The new fused selection has approximately **4.6% higher observed throughput**
than the previous packed-layout selection. This is an internal configuration
comparison, not a comparison with another compiler or a board measurement.
Three frames do not certify asymptotic throughput. At these observed intervals,
30 FPS would require about **114.23 MHz**, but no full-model routed clock or
fabric-feasible buffer allocation has been established.

The graph is unchanged numerically and still scores **0.656095 validation Dice**.
Its model SHA-256 remains
`65397db0d0d3c289e771d5029c74af1a2ebd817c36e07e76269a0ac7c52f920f`.
The best full-range INT8 candidate remains at 0.667115, also below the required
0.676843.

## Lighting-augmentation training experiment

The retained full-range QAT checkpoint was continued for 50 epochs with a fresh
AdamW optimizer and learning rate 0.00003. The architecture, frozen calibrated
quantization scales, original split and zero decision threshold were unchanged.
The experiment adds per-image contrast factors in `[0.9, 1.1]` and brightness
offsets in `[-0.04, 0.04]` on normalized training crops. Spatial labels and cached
teacher predictions remain aligned; the latter serve as an invariant soft target
for the altered image. Evaluation/deployment preprocessing is unchanged.

**The best checkpoint remained epoch zero**, at Dice 0.667115. The experiment
did not improve accuracy and is not adopted. Its integer export matches QAT on
all 246 images and the reloaded export on all 49 validation images; no floating
tensor nodes remain. Validation has been used repeatedly for architecture and
checkpoint selection, and no independent test set was supplied.
